# Free-Trade-Aggrement-FTA-A-Case-Study-on-the-Impact-of-FTA-on-Trade-Flow
This project analyzes the impact of the India–Japan FTA on bilateral trade using time-series methods. It examines trade stability, structural breaks, volatility, forecasting, and economic factors using ARIMA, ARIMAX, ARCH/GARCH, VAR, VECM, and Granger causality.
